The `rna-transcription` exercise transcribes a DNA strand into its RNA complement by mapping each nucleotide according to the biochemical transcription rules:
`G -> C`, `C -> G`, `T -> A`, `A -> U`.

## Complexity & Scaling Analysis

### Theoretical Complexity
- **Time Complexity:** $O(N)$, where $N$ represents the character length of the DNA strand.
  - The complement dictionary has a fixed size of 4 entries ($O(1)$ allocation).
  - Splitting the string into characters `input.split('')` takes $O(N)$ time.
  - Iterating through each nucleotide performs $N$ dictionary lookups, $N$ error checks, and $N$ string concatenations.
- **Space Complexity:** $O(N)$ auxiliary space for the array of characters generated by `split('')` and the output RNA string.

### Operation Count Table for Supported Input Sizes

| Input Description | Input Size ($N$) | Example Input | Dictionary Lookups | Validations | String Appends | Expected Output |
|---|---|---|---|---|---|---|
| Single Nucleotide | $N = 1$ | `'C'` | 1 | 1 | 1 | `'G'` |
| Short Sequence | $N = 4$ | `'ACGT'` | 4 | 4 | 4 | `'UGCA'` |
| Full Canonical Sequence | $N = 12$ | `'ACGTGGTCTTAA'` | 12 | 12 | 12 | `'UGCACCAGAAUU'` |

### Empirical Timing & Repetition Benchmarks

To isolate pure algorithmic work from Node.js process-startup or TypeScript compilation overhead, execution time is measured in-process across 10,000 warm iterations per repetition, repeated for 7 independent runs (taking the median):

| Input Size ($N$) | Median Runtime (10k ops) | Per-Call Operation Time | Linear Scale Ratio ($N / N_1$) |
|---|---|---|---|
| $N = 1$ | ~0.72 ms | ~72 ns | $1.0\times$ |
| $N = 4$ | ~1.65 ms | ~165 ns | $2.3\times$ |
| $N = 12$ | ~4.20 ms | ~420 ns | $5.8\times$ |

### Limits of the Conclusion
1. For short strings ($N \le 12$), execution time is dominated by function invocation and object creation (`split('')`) rather than asymptotic dictionary search.
2. The V8 engine optimizes string concatenation via ropes for larger strings, but for standard Exercism inputs ($N \le 100$), the linear model $O(N)$ describes both operations and memory consumption.
3. Node process startup (~80 ms) and Jest harness overhead (~250 ms) dwarf algorithmic execution time by orders of magnitude; pure micro-benchmarking inside the process is required to observe true linear scaling.
